#My First Project in Machine Learning
#Project Overview
The Personal Expense Tracker is a python-based project that helps users record,organize,and analyze thier daily expenses.It uses the pandas and Numpy libraries to process expense data stored in CSV file and generate useful financial summaries.
#Features
-Load expense data from a CSV file
-Calculate total expenses
-Find the highest expense
-Find the lowest expense
-Generate category-wise expense summary
-Generate monthly expense summary
-Save the summary to a CSV file
#Technologies
-Python
-Pandas
-NumPy
-Google Colab
#Project structure
Personal Expense Tracker
__expense .CSV
__summary.CSV
__README.md
#Dataset
The project uses a CSV file named**expense .CSV**with the following columns:
-Data
-Category
-Description
-Amount
#Output
The program displays:
-Total Expense
-Average Expense
-Highest Expense
-Lowest Expense
-Category-wise Expense Summary
-Monthly Expense Summary
-Confirmation message after saving the summary file
#How to Run
1.Open the project in Google Colab.
2.Upload the 'expense,CSV'file
3.Run all code cells in order.
4.The program will create a 'Summary.CSV'file containing the category-wise expense summary.
